# 🌳 Decision Tree Classification Using Machine Learning

## 📌 Project Overview
This project implements a Decision Tree Classification model using Python and Scikit-learn. It uses the Iris dataset to classify flowers into different species based on their features.

## 🎯 Objectives
- Understand the Decision Tree algorithm.
- Train a supervised machine learning model.
- Predict flower species using input features.
- Evaluate model performance using classification metrics.
- Visualize the decision tree structure.

## 🛠️ Technologies Used
- Python 🐍
- Pandas
- Matplotlib
- Scikit-learn
- Google Colab / Jupyter Notebook

## 📊 Dataset
**Iris Dataset**
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

**Target Classes:**
- Setosa
- Versicolor
- Virginica

## ⚙️ Machine Learning Algorithm
- Decision Tree Classifier
- Criterion: Gini
- Maximum Depth: 3

## 📈 Model Evaluation
- Accuracy Score
- Confusion Matrix
- Precision
- Recall
- F1-Score

## 🚀 Key Features
- Data loading and preprocessing
- Model training and testing
- Flower species prediction
- Decision tree visualization

## 📌 Conclusion
The Decision Tree Classification model successfully demonstrates how supervised machine learning can classify flower species based on input features. It provides an easy-to-understand approach to making predictions using decision rules.
